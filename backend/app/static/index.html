当前已缓存历史行情标的明细
01 · CORPORATE-ACTION ADJUSTED PRICING

所有收益率与回测信号均严格采用复权价格 (adjClose 与 adjOpen)，自动纳入历史拆股 (Stock Splits) 与现金分红复投因子，避免除权日产生虚假暴跌信号（已通过 AAPL 2020 年 1 拆 4 拆股样本检验）。

Simple Return r_t = (adjClose_t / adjClose_{t-1}) - 1
Wealth Index W_t = adjClose_t / adjClose_0 (W_0 = 1.0)
02 · ANNUALIZED RISK & SHARPE METRICS

统一采用每年 252 个交易日 与默认 0% 无风险利率 假设，使用日简单收益率样本标准差计算年化波动率与夏普比率，并实时追踪峰值回撤 (Underwater Drawdown)。

Annual Return = (1 + TotalReturn)^(252 / N) - 1
Sharpe = (mean(r) / stdev(r)) * sqrt(252)
Drawdown_t = (W_t / max_{0..t}(W)) - 1
03 · BENCHMARK BETA & PORTFOLIO FRONTIER

多资产与基准分析自动对共同交易日求交集对齐；组合支持任意权重配置与网格遍历，精确识别最高夏普比率 (Max Sharpe) 与最小方差波动 (Min Volatility) 配比。

Beta = Cov(r_asset, r_bench) / Var(r_bench)
W_portfolio(t) = sum_i [ w_i * (adjClose_{i,t} / adjClose_{i,0}) ]
04 · ZERO LOOK-AHEAD BIAS & OUT-OF-SAMPLE

均线交叉信号在 t-1 日收盘后由 adjClose 生成，调仓指令严格延后至 t 日开盘价 adjOpen 成交，扣除双边换手交易成本 (bps)；样本外验证按时间顺序切分训练集寻优并在未见测试集上独立评估。
